# Quickstart: Contacts Inventory (Deb acceptance)

1. Start API + Web (Docker or local) against a fresh or migrated DB.
2. Open **Vault → Contacts**. Confirm seeded Election contacts (County Clerk, SOS Elections, Canvass Board).
3. **Add** contact “Election – County Clerk” (or edit seeded) with address, office, email, phone; tag **Election**.
4. Open **Requirements → Election Canvass & Certification → Edit**.
5. Use **Pick contact** → select County Clerk as primary. Confirm Contact name/email/phone fill; set **Submit to** (e.g. County Clerk’s Office).
6. Save. Soft-delete a contact from Vault and restore it.
7. Settings / audit: confirm Create / Link entries for Contact / Requirement.
